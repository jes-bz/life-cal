iPhone Automation Guide

Set up your iPhone to automatically update its lock screen every week.

Step 1: Create the Shortcut

  1. Open the Shortcuts app and tap +.
  2. Add these 4 actions in order:
    • URL: Paste the URL from above.
    • Get Contents of URL: Get contents of Text.
    • Get Images from Input: Get images from Contents of URL.
    • Set Wallpaper: Set Lock Screen to Images. Turn OFF "Show Preview".

Step 2: Schedule It

  1. Go to Automation tab -> New Automation.
  2. Choose Time of Day (e.g., Weekly, Monday 9AM).
  3. Select Run Immediately.
  4. Select the Shortcut you just created.
