Set Up Life Calendar on iPhone

Install the signed Shortcut once, then send these settings from this page. Scriptable generates and saves the wallpaper locally on your iPhone; no wallpaper server is needed.

1. Install the iPhone tools

Install Scriptable Add Life Calendar Shortcut

After adding the Shortcut, return to this page to continue.

2. Choose the wallpaper to update

In Life Calendar, edit the final Set Wallpaper Photo action and choose the Lock Screen wallpaper to update. Leave preview and crop options off.

3. Load these settings

Tap the button to open Life Calendar on this iPhone with the settings currently selected on this page. Review them in Scriptable, approve first-run permissions, then tap Save & Refresh Wallpaper.

Change settings later

Use this page’s preview and Apply to iPhone to send a new design. To edit the values already saved on your phone, open the iPhone settings editor.

Optional: refresh weekly

Enable the imported Time of Day trigger in the Shortcut’s Edit → Automation section. If there isn’t one, create a weekly Time of Day automation with Run Immediately and Run Shortcut → Life Calendar; leave input empty.

The settings handoff includes your birth date and selected options. It opens Shortcuts on this iPhone; nothing is sent to a wallpaper server. Don’t share the handoff URL.
